# Release v2 — Platform wedge (council-revised)

> Council verdict 2026-05-28: v2 was **revised** from "ship everything" to a thin traction-gated wedge. The full original v2 (auth + social graph + comments + AI cuts + record-in-browser + PWA + digest + analytics) is too many greenfield backends to land together on a zero-backend codebase. We ship the convergent wedge below; the rest is deferred until the v0/v1 share loop proves session traction.

## Wedge scope (council-approved)

1. **Vercel auth + persistent upvotes + persistent follow**
   - Use "Sign in with Vercel" OAuth (GA Nov 2025) — no custom auth surface
   - Wire existing display-only upvote and follow buttons to real persistence
   - Add `POST /api/upvote/[demoId]` and `POST /api/follow/[founderSlug]`
2. **Postgres via Marketplace**
   - Neon Postgres provisioned via Vercel Marketplace
   - Schema: `users`, `upvotes`, `follows`, `submissions` (v1 carry-forward)
3. **PWA + iOS share-target**
   - `app/manifest.ts` exporting valid PWA manifest
   - Web App Manifest `share_target` so YouTube share-sheet can target Demo Hunt's `/submit`
   - Service worker for offline shell (optional)
4. **Basic Resend digest**
   - Vercel Cron at `0 16 * * *` UTC (9am PT) fires `/api/cron/digest`
   - Pulls top 10 demos from last 24h, sends via Resend to opt-in users
   - Opt-in checkbox added to `/submit` and to footer

## Explicitly DEFERRED

- Comments (server-stored, threaded)
- Notifications (in-app or email)
- Full follow graph / follower feed
- AI pitch coaching cuts (AI Gateway)
- Record-in-browser via MediaRecorder
- Vercel Blob ingest for founder uploads
- Founder analytics dashboard

These wait for v2.1 once we know the basics drive sessions.

## Gating condition

**Do not start v2 until at least one of**:
- v0/v1 share loop drives >= 5 net-new sessions/day from share traffic for 7 consecutive days
- A founder explicitly requests persistent upvotes
- A VC explicitly requests a follow feed

Verify via `@vercel/analytics` dashboard (mounted in v0).

## Implementation plan — three worktree-parallel agents

### Agent A — `v2:pwa` (worktree on `release/v2-pwa`)
- Create `src/app/manifest.ts` exporting `MetadataRoute.Manifest` with name, icons, theme, share_target
- Create `src/app/icon.tsx` + `src/app/apple-icon.tsx` (Next 16 dynamic icons)
- Add `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style` meta tags in layout.tsx viewport export
- Test: install on iOS Safari, verify share sheet shows "Demo Hunt"
- No backend, no DB

### Agent B — `v2:auth-db` (worktree on `release/v2-auth-db`)
- Provision Neon Postgres via Vercel Marketplace CLI:
  - `vercel integrations install neon` (or via dashboard)
  - Pull env: `vercel env pull .env.local`
- Install: `@vercel/postgres` (or `@neondatabase/serverless`) + `@vercel/oauth`
- Schema migration at `db/schema.sql`:
  ```sql
  CREATE TABLE users (id TEXT PRIMARY KEY, vercel_id TEXT UNIQUE, name TEXT, email TEXT, created_at TIMESTAMPTZ DEFAULT now());
  CREATE TABLE upvotes (user_id TEXT REFERENCES users(id), demo_id TEXT, created_at TIMESTAMPTZ DEFAULT now(), PRIMARY KEY (user_id, demo_id));
  CREATE TABLE follows (user_id TEXT REFERENCES users(id), founder_slug TEXT, created_at TIMESTAMPTZ DEFAULT now(), PRIMARY KEY (user_id, founder_slug));
  ```
- Add `src/app/api/auth/sign-in/route.ts` (initiate OAuth)
- Add `src/app/api/auth/callback/route.ts` (handle code, upsert user, set session cookie)
- Add `src/app/api/upvote/[demoId]/route.ts` (POST: insert; DELETE: remove)
- Add `src/app/api/follow/[founderSlug]/route.ts` (POST/DELETE)
- Wire `src/components/upvote-button.tsx` and `src/components/follow-button.tsx` to call the APIs when signed in (fall back to localStorage when anon)

### Agent C — `v2:digest` (worktree on `release/v2-digest`)
- Install: `resend`
- Add `vercel.ts` with `crons: [{ path: '/api/cron/digest', schedule: '0 16 * * *' }]`
- Create `src/app/api/cron/digest/route.ts`:
  - Authenticate cron via `CRON_SECRET` header
  - Compute top 10 demos by `(upvotes + views/100)` from last 24h
  - For each subscriber in `users` table with `digest_opt_in:true`, render an HTML email and send via Resend
- Add opt-in checkbox to `/submit` (carry through to v1's API) and to a new `/subscribe` page
- Env: `RESEND_API_KEY`, `CRON_SECRET`

## Acceptance

- [ ] Sign in with Vercel works end-to-end (sign in, see your handle in nav)
- [ ] Upvote persists across logout/login
- [ ] Follow persists across logout/login
- [ ] PWA installable on iOS Safari with share-target
- [ ] At least one digest email sent (manual trigger of cron URL)
- [ ] Lighthouse mobile score >= 95 on home feed
- [ ] `npm run build` clean, `vercel deploy --prod` succeeds

## Out of scope for v2

Comments, full follow graph, founder analytics, in-browser recording, AI cuts, Blob storage. Each is its own future release.
