# Release v2 — Platform features (auth, social graph, creator tools)

## Goal
Turn Demo Hunt from a curated catalog into a two-sided platform that founders return to and viewers subscribe to.

## Scope
1. **Authentication** — Sign in with Vercel for v2 (no custom auth surface). Profile defaults to viewer; founders can request "founder" role.
2. **Real social graph** — Follow persists server-side. Followers count is real. Email when a founder you follow posts.
3. **Comments** — server-stored, threaded, founder badge for OP replies. Resend-backed email on reply.
4. **Founder dashboard**
   - Upload your pitch script (markdown)
   - Get AI coaching cuts (AI SDK v6 via Vercel AI Gateway, `anthropic/claude-sonnet-4.5` default)
   - Record-in-browser via MediaRecorder API
   - Upload directly to Vercel Blob; serve via Mux ingest for HLS
5. **Daily / weekly / monthly digest** — opt-in at signup; uses Vercel cron + Resend transactional API
6. **Mobile PWA**
   - Web app manifest, installable
   - iOS share-target so the YouTube app's "Share to" sheet can send links into our submit flow
7. **Founder analytics** — view counts per demo, top referrers, vote velocity

## Storage upgrade
- v1 SQLite was a transition. v2 moves to a marketplace Postgres (Neon or Vercel Postgres Marketplace integration).
- Vercel Blob for video assets.
- Vercel KV-replacement (Upstash via Marketplace) for view-count counters.

## Out of scope for v2
- Native iOS/Android apps (PWA only)
- Live streaming
- DM between founders and VCs

## Acceptance
- [ ] Anonymous users can browse; signed-in users can follow/upvote/comment persistently
- [ ] A founder can record a demo in browser and publish to the feed without leaving the page
- [ ] At least one email digest fires nightly with the top 10 demos from prior 24h
- [ ] Lighthouse mobile score >= 95 on the home feed
- [ ] PWA installable on iOS Safari and Chrome Android
