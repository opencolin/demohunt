# Release v0 — Real YC Demos (YouTube only)

## Goal
Replace remaining test content with verified demos from real YC companies funded in the last 3 years (W23 → W26).

## Constraints
- Only YouTube videos in v0. No Loom, no Mux, no other providers.
- Don't break existing Cerebral Valley or ETHGlobal demos already imported.
- No fabricated metadata. Every demo must map to a real, currently-funded YC company.

## Data sources (priority order)
1. **YC Demo Day playlists on YouTube** — `youtube.com/@ycombinator/playlists` has W23 / S23 / W24 / S24 / F24 / W25 / S25 / F25 demo day collections. Each playlist video is one company's pitch.
2. **YC company directory** — `ycombinator.com/companies?batch=W24` gives company name, slug, founder names, batch, website, tags. Cross-ref to the playlist title.
3. **YC Launches** — `ycombinator.com/launches` for shorter "we launched X" video posts.

## Per-demo data we need
| Field | How to get it |
|---|---|
| `videoId` | YouTube watch URL on the playlist |
| `title` | Company name + " — " + one-line pitch (from YC profile or video title) |
| `tagline` | First sentence of YC's company description |
| `description` | Full YC company description |
| `founderSlug` | Slug of first founder from YC profile |
| `category` | Map YC sector tags → our category (AI / Devtools / Bio / Climate / etc.) |
| `tags` | YC tags + `"YC W26"` / batch tag |
| `durationSec` | YouTube oEmbed or `?` (skip if not available; default 120) |
| `source` | `"demo-day"` |
| `sourceLabel` | `"YC {batch} Demo Day"` |

## Founder data
| Field | Source |
|---|---|
| `slug` | kebab-case full name |
| `name` | From YC profile |
| `handle` | From X.com link on YC profile, else lowercase slug |
| `avatar` | First letter of first + last name |
| `bio` | One-line role + company from YC profile |
| `location` | From YC profile if available |
| `email` | From YC profile if public; else `firstname@{companydomain}` |
| `links` | `[{label: company domain, url: company URL}]` + X handle if present |
| `verified` | `true` for all YC founders |
| `badges` | `["YC {batch}", ...sector tags from YC]` |
| `followers` | Skip in v0 — leave undefined |

## Acceptance
- [ ] >= 80 new demos added with `source: "demo-day"` and `sourceLabel` starting `"YC "`
- [ ] Every new founder has `verified: true` and at least one badge starting `"YC "`
- [ ] No new founder slug collides with an existing one
- [ ] `npm run build` passes
- [ ] Local preview at `/demo/{id}` plays the YouTube video for the first 5 new demos
- [ ] `docs/STATE.md` updated

## Owner agents
- `yc-playlist-scraper` — scrape YC YouTube channel for batch demo day playlists, return per-batch video list (ID, title)
- `yc-directory-mapper` — for each video title, fuzzy-match to a YC company directory entry, return enriched record
- `yc-importer` — write enriched records into `src/lib/data.ts` (worktree, opens PR to `release/v0-yc-import`)
- `qa-bot` — visit first 5 new demo URLs, screenshot, confirm play
