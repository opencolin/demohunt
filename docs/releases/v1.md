# Release v1 — Multi-source aggregation + creator pipeline

## Goal
Make Demo Hunt the broadest catalog of video startup pitches on the public web, and open the door for founders to add their own.

## Scope additions over v0
1. **More sources** (in priority order)
   - Devpost — major hackathon submissions with embedded YouTube
   - AI Tinkerers events (Tinkerers.club YouTube)
   - AGI House recorded talks
   - MIT AI Studio playlist
   - Anthropic Builder Club demos
   - YC Launches video clips
   - Browser Use Discord pinned showcase
   - Founders' own X/Twitter pitch threads (Twitter Cards → embed)
2. **One-click submission** at `/submit`
   - Paste YouTube or Loom URL → oEmbed lookup → auto-fill title, thumbnail, duration
   - Founder enters their name + handle + 1-line tagline
   - Goes live immediately, gets the "Founder upload" source badge
3. **Real durations everywhere** — replace random durationSec defaults using:
   - YouTube oEmbed `duration` (when present)
   - Mux Asset API for our own uploads (none yet)
   - Loom API for Loom URLs
4. **Persistence** — move from `src/lib/data.ts` arrays to a SQLite file checked into the repo. PR-based moderation. Each submit appends one row.

## Out of scope for v1
- Auth (still no login; submission collects email but doesn't gate)
- Comments persistence (still client-only)
- Email digest delivery
- Mobile push

## Acceptance
- [ ] >= 150 net-new demos from sources beyond YC + Cerebral Valley + ETHGlobal
- [ ] `/submit` accepts a YouTube URL and within 2 seconds shows the demo on the home feed
- [ ] Every demo has a non-random `durationSec`
- [ ] Persistence file lives at `data/demohunt.db` and `npm run build` reads it
- [ ] `docs/STATE.md` updated
